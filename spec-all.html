AI向け仕様書（テスト用ダミー・単一ファイル版 test-0.1）

実現可能性調査用に、index／spec／sample を1ファイルへ統合した版です。 参照ファイルをたどれないAIでも、このファイル1つで完結するようにしています。

重要ルール

  • 制作に必要な情報が不足していれば利用者に質問する。ただし、この会話ですでに判明していることは聞き直さない
  • 構成案を利用者に提示し、確認が取れてからシナリオを生成する
  • 利用者が文章をそのまま渡した場合は、言い換えずにそのままシナリオへ入れる
  • 最終成果物は下記の専用形式どおりに、JSONのみをコードブロックで出力する
  • このファイルが読めない場合は、推測で進めず、利用者にファイルの添付を依頼する

専用形式

JSONで、次のフィールドだけを使うこと。余分なフィールドは入れない。

フィールド 型 内容
formatVersion 文字列 "test-0.1" 固定
title 文字列 動画タイトル
target 文字列 対象者（例：小学校高学年）
durationSec 数値 尺の目安（秒）
bgm 文字列または null BGMの雰囲気を表すID（例："bright"、"calm"、"serious"）。不要なら null
lines 配列 セリフの並び。各要素は speaker と text

lines の各要素：

フィールド 型 内容
speaker 文字列 "A" または "B"（二人組の掛け合い）
text 文字列 セリフ本文。そのまま読み上げられる文章

制作ルール

  • セリフは二人（A・B）の掛け合いで構成する
  • 利用者がそのまま使うよう指定した文章は、言い換えずに text へ入れる
  • 尺の目安に収まる分量を意識する（日本語で概ね1分あたり250字程度が目安）
  • 生成前に構成案（タイトル・対象者・尺・流れ）を提示し、利用者の確認を取る
  • 生成時はJSONのみをコードブロックで出力し、前後に説明文を付けない

サンプル

{
  "formatVersion": "test-0.1",
  "title": "雨の日の安全な帰り道",
  "target": "小学校低学年",
  "durationSec": 120,
  "bgm": "calm",
  "lines": [
    { "speaker": "A", "text": "雨の日は、傘で前が見えにくくなるよね。" },
    { "speaker": "B", "text": "ほんと。だから横断歩道では一度止まって、左右をよく見るんだ。" },
    { "speaker": "A", "text": "水たまりも滑りやすいから、走らないことも大事だね。" }
  ]
}
